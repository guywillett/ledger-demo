# Guarantees

What the system promises, how each promise is kept, and the tests that show it. Each row claims one guarantee; *How* names the mechanism (with the spec decision that argues it), and the test columns name the tests to read or run, in both implementations. Quoted names are Node's test cases; Go's tests are named after them (the pairing is in [slice-3-test-map.md](slices/slice-3-test-map.md)). `scripts/demo.sh` shows several against the running system, on every stack (see [development.md](development.md#the-demo)).

To check a row: read its tests, or run them (`npm test` in `node/`, `go test -race ./...` in `go/`, with `docker compose up -d`; [development.md](development.md)).

Decision numbers refer to the Decisions sections of the [slice 1](slices/slice-1-incoming-payments.md), [slice 2](slices/slice-2-outbox-and-withdrawals.md), [slice 3](slices/slice-3-go.md) and [slice 5](slices/slice-5-observability.md) specs. Node paths are under `node/test/`, Go paths under `go/internal/`.
